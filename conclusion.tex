\chapter{Conclusion and Future Scope}

\section{Conclusion}
This report presented a communication-domain Phase 2 extension of the Phase 1
automatic modulation classification project. Phase 1 developed and measured a
compact CNN for raw I/Q modulation recognition using RadioML 2016.10a. It
achieved 53.94\% held-out test accuracy and provided the baseline
representation-learning component.

Phase 2 used modulation information as part of an adaptive digital receiver.
The complete simulation includes random-bit generation, BPSK, QPSK, 8-PSK,
and 16-QAM modulation, block-Rayleigh fading, AWGN, carrier phase and
frequency offsets, synchronization, equalization, modulation selection,
demodulation, and bit-level evaluation. The system was evaluated using BER,
SER, packet success, modulation-decision accuracy, and effective throughput.

At 16 dB SNR, the adaptive receiver achieved 0.095\% BER, 0.172\% SER, 100\%
modulation-decision accuracy, 75.5\% packet success, and 1.888 bits/symbol
effective throughput. At 10 dB, the receiver achieved 99.5\% decision
accuracy and 4.69\% BER. These results demonstrate that the principal Phase 2
contribution is not simply a changed CNN architecture; it is the integration
of signal recognition with communication-system operation.

\section{Future Scope}
\begin{enumerate}
\item Replace the constellation estimator with a trained online neural
      classifier operating on synchronized I/Q frames.
\item Add pulse shaping, matched filtering, timing recovery, carrier recovery,
      and automatic gain control to form a more complete PHY receiver.
\item Introduce convolutional or LDPC channel coding, interleaving, and
      automatic repeat request to improve low-SNR packet reliability.
\item Evaluate Rician and frequency-selective fading, multipath delay,
      Doppler, oscillator phase noise, and nonlinear power-amplifier effects.
\item Add confidence-aware fallback: when the modulation decision is
      uncertain, use a robust mode or request retransmission.
\item Port the receiver to GNU Radio and validate it with an RTL-SDR,
      HackRF, USRP, or another suitable SDR platform.
\item Compare energy consumption, latency, throughput, and memory use on
      embedded hardware.
\item Extend the evaluation to a real over-the-air dataset and compare
      cross-domain generalization against the synthetic benchmark.
\end{enumerate}

\section{Final Statement}
The Phase 2 project establishes a reproducible foundation for an intelligent
adaptive receiver. The measured results are sufficiently concrete for
comparison and discussion, while the limitations identify a clear path from
simulation to hardware-supported communication research.
